This portfolio is built with Next.js, Tailwind CSS and Motion, and it is deployed on Vercel. Here is how I approached it.

## Start with the content

Before writing any code, I wrote down my projects: the problem, my role, the stack and the result. A portfolio is only as good as the stories it tells.

## Keep animations purposeful

I picked one signature effect for the hero and kept everything else subtle. I also respect `prefers-reduced-motion`, so people who ask for less movement get it.

```tsx
const reduce = useReducedMotion();
```

## Deploy early

I pushed the repository to GitHub on day one and connected it to Vercel. Every push became a live preview, which made feedback instant.

> Ship the boring version first, then make it beautiful.
